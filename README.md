# json-resume-schema
PHP 8 implementation of the [JSON Resume schema](https://www.jsonresume.org/schema).

## Installation
```shell
composer req inwebo/json-resume-schema
```

## Coding standards

* [PSR-12](https://www.php-fig.org/psr/psr-12/)
* [PHPStan level 10](https://phpstan.org/user-guide/rule-levels)
